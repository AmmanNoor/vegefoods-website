Vegefoods – Responsive eCommerce Website

Vegefoods is a fully responsive eCommerce website template built using HTML, CSS, and JavaScript. It is designed for an online store that sells vegetables, fruits, juices, and organic products.

🌟 Features

📱 Responsive Design – Works seamlessly on desktop, tablet, and mobile.

🛒 Product Listings – Display products with images, prices, discounts, and quantity selection.

❤️ Wishlist Page – Add and manage favorite products.

👥 About Us Page – Introduces the store with hero section, counters, testimonials, and features.

📝 Blog Section – Display articles with categories, tags, and sidebar.

📩 Contact Page – Contact form with address, email, and phone details.

⭐ Customer Testimonials – Interactive slider showcasing customer reviews.

🔗 Navigation with Smooth Scrolling – Easy and modern navigation experience.

📧 Newsletter Subscription – Stay connected with customers.

🖼 Modern UI/UX – Clean, minimal, and user-friendly design.

🛠️ Technologies Used

HTML5 – Website structure

CSS3 – Styling and responsiveness (Flexbox & Grid)

JavaScript (ES6) – Interactivity and dynamic features

Font Awesome – Icons

Google Fonts – Typography
